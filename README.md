# 두도 포인트 – 부산 두도·인근 갯바위 낚시 확률 앱 (안드로이드)

그날의 날씨·물때·수온·시간대를 점수(0~100)로 계산해서 **어느 포인트에서, 몇 시에, 어떤 어종을 노리면 좋은지** 순위로 보여주는 앱입니다.

## 1. 실행 방법

1. [Android Studio](https://developer.android.com/studio) 설치 (최신 버전)
2. 압축을 풀고 Android Studio에서 **File → Open → `DudoFishing` 폴더** 선택
3. 처음 열면 Gradle 동기화(필요한 라이브러리 다운로드)가 몇 분 걸립니다
4. 휴대폰을 USB로 연결(개발자 옵션 → USB 디버깅 켜기)하거나 에뮬레이터를 고른 뒤 ▶ 실행

### GitHub에서 APK 받기 (Android Studio 없이)

`main` 브랜치에 push하면 GitHub Actions가 자동으로 APK를 빌드합니다.
저장소의 **Actions** 탭 → 최신 "Build APK" 실행 → 아래쪽 **Artifacts**의 `dudo-fishing-debug-apk`를 내려받아 압축을 풀고 휴대폰에 설치하세요(출처를 알 수 없는 앱 설치 허용 필요).

API 키가 없어도 **데모 모드**로 바로 동작합니다(날씨는 가상 데이터, 물때는 달 위치로 추정).

## 2. 실제 데이터 연결 (API 키 발급, 무료)

| 데이터 | 발급처 | 앱 설정 칸 |
|---|---|---|
| 풍속·풍향·파고·강수 | 공공데이터포털 data.go.kr → "기상청_단기예보 조회서비스" 활용신청 | 기상청 인증키 |
| 만조·간조 시각 | 공공데이터포털 "국립해양조사원_조석예보(고, 저조)" 활용신청 (같은 키, 부산 DT_0005). 없으면 해수욕장 서비스 조석정보(송도해수욕장) → 달 위치 추정 순 | 자동 |
| 수온 | 공공데이터포털 "기상청_전국 해수욕장 날씨 조회서비스" 활용신청 (단기예보와 **같은 키**) | 자동 – 두도에서 가장 가까운 송도해수욕장(268번, 3.5km) 부이 실측. 관측이 없으면 몰운대(164)·다대포(308)·감지해변(165) 순으로 시도, 모두 없으면 월평균 추정. 해변코드 표는 `assets/beaches.json` |

- 앱 오른쪽 위 ⚙ 설정에서 키를 붙여넣고 저장하면 됩니다.
- **키를 앱에 기본으로 넣기(추천)**: GitHub 저장소 → Settings → Secrets and variables → Actions → *New repository secret* → 이름 `KMA_API_KEY`, 값에 인증키(Decoding 키)를 넣으면 이후 빌드되는 APK에 키가 들어가서 설정 입력 없이 바로 연결됩니다. 키는 코드에 남지 않습니다.
- 국립해양조사원 API는 공공데이터포털(`apis.data.go.kr/1192136/...`)로 이전 중입니다. 새 방식 키를 받았다면 `data/TideApi.kt`의 `fetchKhoa()` 주소와 파싱 부분만 새 활용가이드에 맞게 바꾸면 됩니다.

## 3. 점수 계산 방식 (`scoring/ScoreEngine.kt`)

기본 **50점**에서 아래 요인을 더하고 뺍니다. 앱 상세 화면에서 항목별 가감 내역을 그대로 볼 수 있습니다.

| 요인 | 내용 | 범위 |
|---|---|---|
| 시즌 | 어종별 월별 적합도 | −12 ~ +12 |
| 수온 | 적정 범위 +12 / 가능 범위 +2 / 범위 밖 −15 | |
| 대표 어종 | 포인트 대표 어종이 아니면 | −10 |
| 시간대 | 피딩타임(일출·일몰), 볼락은 밤, 벵에돔은 낮 | −12 ~ +15 |
| 조류 | 들물/날물 진행률, 정조 감점, 감성돔·볼락은 중~끝들물 가점 | −6 ~ +14 |
| 물때 | 조금(약함) 감점, 중간 물때 가점 | −5 ~ +8 |
| 바람 | **포인트가 바라보는 방향 기준** 맞바람이면 크게 감점 | −30 ~ +4 |
| 파고 | 감성돔은 0.5~1.2m 포말 가점, 2m 이상 위험 | −30 ~ +6 |
| 비 | 강수 예보 | −4 |

**위험 조건**(풍속 12m/s 이상, 파고 2m 이상, 맞바람+파도 등)이면 점수를 15점 이하로 묶고 경고를 표시합니다.

어종별 기준값은 `scoring/Species.kt`에서 숫자만 바꿔 조정할 수 있습니다.


## 3-1. 포인트별 차등 요인 (v0.6)

| 요인 | 내용 |
|---|---|
| 찌낚시 조류 | 들물은 북동(60°), 날물은 남서(240°)로 흐른다고 보고(`scoring/Factors.kt`의 `FLOOD_FLOW_DEG`, `EBB_FLOW_DEG`), 포인트가 바라보는 방향과 비교. 조류가 앞으로 뻗으면 +7, 옆으로 흐르면 +3(곶부리 +3 추가), 갯바위로 받히면 −6 |
| 지형 × 물때 | 센 조류(사리·중들물)엔 홈통 +5·곶부리 −4, 약한 조류(조금)엔 곶부리 +5·홈통 −3 |
| 어종 × 수심·지형 | 감성돔은 4~6m 여밭 +6(조행기 근거), 벵에돔은 8m 이상 +4, 볼락은 여밭·홈통 +3, 무늬오징어는 곶부리·직벽 +3 |
| 과거 조과 | `assets/catches.json`(공개 조행기) + 앱에서 남긴 내 기록. 물때·계절이 비슷하고 바람·파고·수온·시간대가 비슷할수록 최대 +18. 조행기 날짜의 바람·파고·수온은 휴대폰에서 Open-Meteo 과거자료로 한 번 받아 저장 |

| 은파낚시 밴드 조황 | 선장 일일 조황 약 70일치(2025.8~2026.10)를 날짜·어종·조황 등급으로 요약해 `catches.json`에 포함(개인정보·원문 미포함). 부진했던 날과 비슷한 조건이면 감점(최대 −8) |
| 물돌이 | 밴드 조황에서 대물 감성돔은 물돌이 전후 입질이 반복 확인 → 감성돔은 시간대에 만조·간조가 들어 있으면 +7, 정조 감점 없음 |
| 남서풍 | 남서풍에 수온이 내려가 조황이 떨어진 기록 → 남서풍 4m/s 이상 −3 |

점수는 가감 합계를 곡선으로 변환합니다(합계 +38 ≈ 50점, +60 ≈ 72점).

### 조과 기록 남기기
포인트 상세 화면 아래 **내 조과 기록하기**에 마릿수를 넣고 저장하면, 그 시간대의 물때·바람·파고·수온이 함께 저장되고 다음부터 비슷한 조건일 때 그 포인트 점수가 올라갑니다. 기록이 쌓일수록 정확해집니다.

## 4. 포인트 수정·추가 (`app/src/main/assets/points.json`)

현재 **송도 두도(부산 서구 암남동) 1~18번, 0.5번 포인트, 직벽** 총 27곳이 들어 있습니다. 번호와 수심은 두도 포인트 지도(송도 은파낚시) 기준입니다.

⚠ **좌표와 바라보는 방향은 지도 사진에서 추정한 값입니다.** 지도에서 실제 위치를 찍어 고쳐주세요.

- `depthMin`, `depthMax`: 수심(m). 10m 이상 포인트는 사리 때 조류 감점을 받지 않습니다.

- `facingDeg`: 갯바위가 바다를 바라보는 방향(0=북, 90=동, 180=남, 270=서). 바람 점수에 직접 쓰이므로 가장 중요한 값입니다.
- `species`: 그 포인트의 대표 어종 (감성돔, 벵에돔, 볼락, 무늬오징어)
- 수정 후 `"coordVerified": true`로 바꾸면 앱의 좌표 경고가 사라집니다.

## 프로젝트 구조

```
app/src/main/java/com/dudo/fishing/
├─ MainActivity.kt          화면 전환
├─ data/
│  ├─ Models.kt             데이터 구조
│  ├─ PointRepository.kt    포인트 목록 읽기
│  ├─ KmaApi.kt             기상청 단기예보 + 격자 변환 + 데모 날씨
│  ├─ TideApi.kt            조석예보 + 추정 계산
│  ├─ Astro.kt              월령·물때·일출일몰
│  ├─ ConditionsRepository.kt  위 데이터를 모아 하루 조건 생성
│  └─ Settings.kt           API 키 저장
├─ scoring/
│  ├─ Species.kt            어종별 선호 조건
│  └─ ScoreEngine.kt        점수 계산
└─ ui/                      화면 (홈 / 상세 / 설정)
```

> 점수는 참고용입니다. 갯바위 출조 전 기상특보, 출입 통제 여부, 현장 상황을 반드시 확인하세요.
